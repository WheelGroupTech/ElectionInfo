# California County Election Information

For each of the 58 California counties: the county elections official (who is also the voter registrar), per the California SOS County Elections Offices list; whether a registered-voter list can be downloaded; the elections website; the historical election-results location and the record types posted for 2020-present; the California Public Records Act route; and the voting technology in use, per the SOS 'Voting Technologies in Use by County' table.

Researched 2026-10-09. Machine-readable copies: `california_county_election_info.json` (canonical) and `california_county_election_info.csv`.

## Summary

- **Counties:** 58
- **Voting system:** Liberty Vote (formerly Dominion Voting Systems): 39 counties; Hart InterCivic: 13 counties; Election Systems & Software (ES&S): 5 counties; Los Angeles County (VSAP): 1 counties. Per the SOS 'Voting Technologies in Use by County' table.
- **Voter list:** No free public download in any county. Available only to qualified requesters by application to the county or the SOS (Elections Code 2188, 2194).
- **County results posted on county sites:** 54 counties.
- **Cast vote records posted on county sites:** Colusa, El Dorado, Placer, San Francisco, Sierra.
- **Ballot images posted on county sites:** San Francisco.
- **EMS audit logs posted online:** Inyo, San Francisco.
- **Ballot transfer / chain-of-custody logs posted online:** Inyo.
- **Results tapes / zero reports posted online:** 3 counties.
- **Voter rosters / numbered lists posted online:** none found.
- **Post-election audit reports posted online:** 11 counties.
- **Reconciliation reports posted online:** 1 counties.
- **Open records:** 32 counties have an online request portal or request page; the rest take written California Public Records Act requests by mail, email or in person.

## Notes

- County elections officials, titles, addresses, phones, faxes and emails come from the California SOS County Elections Offices list (https://www.sos.ca.gov/elections/voting-resources/county-elections-offices), retrieved 2026-10-09. In California the county elections official (a Registrar of Voters, or the County Clerk or Clerk-Recorder acting as registrar) also maintains voter registration, so voter_registrar repeats the elections official. Alameda and Sutter list no email on the SOS page.
- Voting technology comes from the SOS 'Voting Technologies in Use by County' table, as of April 30, 2026 (https://votingsystems.cdn.sos.ca.gov/oversight/county-vsys/vot-tech-by-counties-2026-1.pdf), which the SOS notes is subject to change. Tabulation vendors: Liberty Vote (formerly Dominion Voting Systems): 39; Hart InterCivic: 13; Election Systems & Software (ES&S): 5; Los Angeles County (VSAP): 1. Liberty Vote acquired Dominion Voting Systems in 2025; the SOS now lists Democracy Suite under Liberty Vote. tabulation.equipment lists one entry per column of the table (central tabulation, vote center tabulator, accessible BMD, ballot on demand, remote accessible vote by mail, electronic pollbook, election management system) with the product named exactly as the SOS lists it; quantities are not published, so quantity is null. The table's 'Election Management System' column (DFM, DIMS, ProVista) is the county's election management / voter registration system, not the tabulation software, which is given in tabulation.ems_software. Vendors are named only where the SOS vendor pages identify the product (Balotar, DFM, DIMS and ProVista are left without a vendor).
- Every California county mails a ballot to every active registered voter. Ballots are paper and are tabulated by optical scan; no county counts by hand in place of machines. AB 969 (2023) bars manual tallies replacing machine counts in elections with more than 1,000 registered voters. Shasta County voters approved Measure B (hand counting, in-person voting, voter ID) in June 2026; courts have blocked it from taking effect.
- Post-election audits: during the official canvass every county must conduct a public 1% manual tally (Elections Code 15360) or, where it opts in, a risk-limiting audit. Counties that post their manual-tally or RLA reports are recorded under hand_count_audit.
- Voter lists: there is no public voter-file download. Elections Code 2188 and 2194 limit the voter file to candidates, ballot-measure committees and people with election, scholarly, journalistic, political or governmental purposes, who apply to the county elections official or to the SOS (Voter Registration Information File Request).
- Cast vote records were found posted on county sites for: Colusa, El Dorado, Placer, San Francisco, Sierra. Ballot images were found for: San Francisco. The SOS does not post CVRs or ballot images statewide.
- records_found_2020_present lists only records found posted on the county's own sites (including dedicated county elections sites and county results pages). It is not exhaustive, and absence means 'not found'. Years come from link text, file names and upload folders; undated items appear on sites whose file links carry no date. Public notices, press releases and drawings for the manual tally are not counted as records.
- Public records: requests go to the county under the California Public Records Act (Gov. Code 7920.000 et seq.). open_records.url is the county's online portal or request page where one was found.
- Deep links change with site redesigns. Start from county_website or the SOS County Elections Offices list if a link breaks.

## Record-type codes

Years are two-digit (`22-24` = 2022–2024); `undated` = items whose year could not be inferred.

| Code | Record type |
|------|-------------|
| RES | Election results (cumulative / precinct) |
| CAN | Official canvass / statement of vote / certification |
| REC | Reconciliation reports |
| HCA | 1% manual tally / risk-limiting audit |
| ROS | Voter rosters / lists of voters |
| TAPE | Results tapes / zero & totals reports |
| HASH | Hash validation / L&A test reports |
| LOG | EMS / tabulator audit or event logs |
| XFER | Ballot transfer / chain-of-custody logs |
| CVR | Cast vote records (CVR) |
| IMG | Ballot images / scanned ballots |
| VF | Full registered-voter file |
